# 가상 채용공고 600개

이 자료는 모의지원과 매칭 시각화를 검증하기 위한 독립적인 합성 공고입니다. 실제 회사의 모집이나 현재 급여 정보를 제공하지 않습니다. 원문의 문장·회사·지원자 자료를 복제하지 않았으며 실제 주소·담당자 연락처도 넣지 않았습니다.

## 구성과 작성

기존 공고 30개와 AI 오케스트레이션 공고 30개의 ID를 보존하고 본문을 보강했습니다. 새 공고 540개는 18개 분야, 54개 직무 원형에서 만들었습니다. 직무마다 직접 작성한 핵심 업무 3개, 자격요건 2개, 우대사항 1개를 두고 실제로 다루는 운영 상황 2개를 조합해 10개 변형을 작성했습니다. 회사명뿐 아니라 해결해야 할 문제와 작업 결과가 달라집니다.

모든 공고에는 회사·팀 맥락, 5개 담당 업무, 자격과 우대사항, 지역·일정·고용형태, 가상 급여, 복리후생, 전형절차와 제출자료 안내가 있습니다. 파트타임은 주 3일·하루 4시간과 시급, 전일제는 근무 일정과 연봉으로 표시합니다. 의료·돌봄 직무는 필요한 자격과 의료진에게 연결해야 하는 업무 범위를 구분합니다.

본문은 1,308~1,476자(평균 1,368자)이며 600개 본문과 회사명이 모두 다릅니다. 회사 소개·급여·혜택이 평가 대상으로 들어가지 않도록 기존 요구사항 추출기가 인식하는 제목을 사용합니다. 중복 기술을 합친 뒤 평가 요구사항은 공고당 4~8개입니다. 상세 공고로 보강하면서 점수는 바뀔 수 있지만 점수 계산법과 60점 기준은 유지합니다.

## 역할별 작성 예시

- Python 백엔드 개발: FastAPI 요청 검증, PostgreSQL 트랜잭션, 통합 테스트가 핵심 업무입니다. 예약 동시성·부분 취소·권한 분리 등의 조합마다 재현해야 할 오류와 검증 항목이 달라집니다.
- 매장 판매: 고객 안내, POS 결제, 상품 진열과 재고를 맡습니다. 신상품 검수·혼잡 시간·교환·예약 수령에 따라 담당자의 확인 항목이 달라집니다.
- 요양보호: 자격 확인을 요구하고 일상생활·이동 보조와 관찰 기록을 다룹니다. 진단과 면허 범위 밖 의료 행위는 의료진에게 연결하도록 적었습니다.

## 재생성과 저장

`scripts/job_catalog_briefs.py`에서 직무별 문장을 편집한 뒤 `python scripts/expand_job_catalog.py`를 실행합니다. 생성기는 DB를 열지 않고 세 공고 JSON과 `expanded_jobs_manifest.json`만 갱신합니다. 원래 60개의 `catalog_original_requirements`는 최초 업무 요약을 보존하므로 반복 실행해도 설명이 누적되지 않습니다.

`JobRepository.seed`는 예시·공개 소유 조건에 해당하는 ID만 갱신합니다. 사용자 공고를 덮어쓰거나 공고를 삭제하지 않으며 북마크가 참조하는 ID도 유지합니다. 새 데이터는 앱을 시작할 때 설정된 DB에 반영됩니다. `tests/unit/test_expanded_job_catalog.py`가 개수·중복·직무 변형·본문 길이·요구사항 경계·급여 단위와 재생성 일치를 검증합니다.
