검토 기준일: 2026-10-02. 이 문서는 프로젝트 2를 우선으로, 프로젝트 1의 기반 항목까지 확인합니다. 평가 점수나 합격 판정은 아니며, 코드 구현과 제출용 증거를 구분합니다.

이 문서는 위 기준일의 검토 기록입니다. 이후 추가된 비회원 분석, 데이터 규모, API 버전과 현재 실행 범위는 저장소 README와 최신 OpenAPI 계약을 확인하세요. 아래의 당시 수치·상태를 현재 전체 구현 현황으로 해석하지 않습니다.

- 평가 기준: [사용자가 지정한 평가표](https://docs.google.com/spreadsheets/d/1PTF-DiHO_BBKDDf7NSLnMHqlDb-L5p8P6__KLI6OHCA/edit?gid=287730879#gid=287730879). 해당 시트의 읽기 전용 CSV에서 P1-0~P1-4, P2-1~P2-2 전체 항목을 확인했습니다.

- 구조 기준: 기존 `api → application → agent/modules`, `retrieval`, `integrations`, `infrastructure` 경계를 유지합니다. 프론트엔드도 기존 `app/pages/features/shared` 구조를 유지합니다.

상태는 `구현`(해당 코드 존재), `부분`(일부 요소만 존재), `미구현`, `실환경 미검증`으로 구분합니다. 모의 도구 시험 통과는 실제 LLM 품질이나 운영 성능의 증거로 대체하지 않습니다.

## 확인한 시험과 수치

2026-10-02 통합 검증에서 백엔드 테스트 96개, 프론트엔드 JavaScript 테스트 14개, Python 프록시 테스트 7개가 통과했습니다. Python 의존성 검사에 충돌이 없었고 OpenAPI 1.2.0 export 및 프론트엔드 snapshot 동기화 검사가 통과했습니다. 브라우저의 모든 화면·기기·외부 제공자까지 이 자동 시험 숫자에 포함되는 것은 아닙니다.

별도 검증 서버와 합성 계정으로 공개 공고 검색, 회원가입, 이력서 20개 선택, 공고를 통한 모의지원, 결과 프레임 내부 스크롤, 관심 저장/해제, 공고 작성/수정/삭제를 브라우저에서 확인했습니다. 375px 화면에서 가로 넘침이 없었고 수집된 console error는 0개였습니다. 세부 관찰과 미검증 범위는 프론트엔드 `tests/e2e/mvp-verification.md`에 기록했습니다.

`scripts/evaluate-agent.py`가 생성한 [원시 평가 결과](../../evaluations/results/agent-baseline-v1.json)의 고정된 합성 오류 5개를 비교합니다. 기준선은 한 번 코칭을 받아 수정/대체 없이 사용하는 시험 조건입니다. 평가 하네스가 결과의 유효성을 검사합니다. 적용 후 조건은 같은 입력·가짜 응답에 현재 그래프의 검증·수정·대체를 사용하는 것입니다. 실제 이전 운영 버전과 신규 운영 버전의 배포 실험이 아닙니다.

| 지표 | 단일 시도 기준선 | 그래프 적용 후 | 해석 |
| --- | --- | --- | --- |
| 유효한 코칭을 얻은 사례 | 1/5, 20% | 2/5, 40% | 주입한 인용 오류 1개가 두 번째 가짜 응답에서 수정됨 |
| 유효하지 않은 코칭 통과 | 3건 | 0건 | 스키마·인용·출처 오류 필터의 동작 |
| 사용 가능한 규칙 보고서로 종료 | 직접 비교 대상 아님 | 5/5, 100% | AI 코칭을 제외한 fallback 3개 포함. AI 작업 성공률과 다름 |
| 기존 규칙 점수 유지 | 직접 비교 대상 아님 | 5/5, 100% | 의미적 답변 일관성이나 정확도 전체를 측정하지 않음 |
| 사례당 평균 재시도 | 0회 | 0.8회, 총 4회 | 오류 수정을 위한 제한된 재시도. 감소 지표가 아님 |
| 자율 도구 선택 정확도 | 미측정 | 미측정 | 고정 호출 정책이므로 실제 자율 선택 시험 필요 |

각 단계의 시험 명령·환경·코드/프롬프트 버전과 결과를 함께 남깁니다. 개인정보가 없는 평가셋을 사용하고 실제 제공자는 각자 `.env`로 연결합니다. 완료 비율은 평가표의 가중치와 채점 규칙이 없으므로 임의의 백분율로 산정하지 않았습니다.

실제 기관·기업에 지원서를 전송하는 기능, 실제 채용 결과나 합격 확률 판단, 개인정보가 포함된 원본 교육/이력서 자료의 재배포는 현재 MVP 기능으로 표시하지 않습니다.
